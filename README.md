## 🧩 My Problem-Solving Workflow

<p align="center">
  <img src="https://img.shields.io/badge/01-Understand%20Problem-0D9488?style=for-the-badge" alt="Step 1"/>
  <img src="https://img.shields.io/badge/02-Brute%20Force-0891B2?style=for-the-badge" alt="Step 2"/>
  <img src="https://img.shields.io/badge/03-Optimize-7C3AED?style=for-the-badge" alt="Step 3"/>
  <img src="https://img.shields.io/badge/04-Test%20Edge%20Cases-DB2777?style=for-the-badge" alt="Step 4"/>
  <img src="https://img.shields.io/badge/05-Analyze%20Complexity-16A34A?style=for-the-badge" alt="Step 5"/>
</p>

For each problem, I try to:

1. Understand the input, output, and constraints.
2. Develop a brute-force solution.
3. Find a better or optimal approach.
4. Write clean and readable Python code.
5. Test normal cases and edge cases.
6. Analyze time and space complexity.
7. Save the solution with a meaningful filename.
