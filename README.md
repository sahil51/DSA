## 📌 My Approach

1. Understand the problem and its constraints.
2. Write a simple brute-force solution.
3. Analyze time and space complexity.
4. Improve the solution where possible.
5. Test edge cases and record what I learned.

## 🔄 Automatic Updates

This repository uses GitHub Actions to refresh supported README sections on a schedule and when code is pushed.

For automatic updates:

- Keep `scripts/update_readme.py` in the repository.
- Keep `.github/workflows/dynamic-dashboard.yml` and `.github/workflows/contribution-snake.yml`.
- Enable **Read and write permissions** for GitHub Actions if the workflows need to commit changes.
- Run both workflows manually once to test them.
- Check the **Actions** tab if a section does not update.

**Note:** Live statistics depend on external services and API availability. LeetCode's data endpoint is unofficial, so some updates may fail temporarily. The GitHub snake also requires its workflow to publish the SVG files successfully.
